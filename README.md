# Simple Calculator

A beginner-friendly calculator built using Python.

## Features

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Power (^)

## How It Works

The user enters:

1. First number
2. Second number
3. Operator

The program performs the selected operation and displays the result.

## Example

Input:

```text
First Number: 10
Second Number: 5
Operator: +
```

Output:

```text
The sum of the numbers are: 15
```
